# 重複清晨 (Recurring Dawn)

一款結合 **時間循環（Time Loop）** 與 **解謎要素** 的網頁探索解謎遊戲。玩家將扮演困在同一天清晨的主角，透過不斷重演的時間片段尋找線索、解開謎題，打破無盡的循環。

---

## 🎮 遊戲玩法

* **時間重複（時間循環機制）**：
  * 每當時間耗盡或觸發特定條件時，時間將重新回到最初的清晨。
  * 玩家在上一輪循環獲得的**關鍵記憶/知識**與**關鍵道具**將會保留，用以解開原本無法觸發的機制。
* **場景解謎與互動**：
  * 在限定的時間內探索場景、調查物品、與環境互動。
  * 推理解開密碼鎖、機關與事件連鎖反應，逐步拼湊出隱藏在清晨背後的真相。

---

## 🤖 使用的 AI 提示詞 (Prompts)

本專案在開發過程中，利用生成式 AI 輔助架構設計與程式碼撰寫，主要使用的提示詞如下：

1. **核心玩法與時間邏輯生成**：
   > 「請幫我設計一個基於 HTML5 Canvas/DOM 的時間循環解謎遊戲邏輯。需包含時間倒數計時器、循環重置 (Reset) 機制，以及在重置後可保留玩家『已獲得記憶狀態 (Global State)』的功能。」

2. **謎題與關卡機制**：
   > 「請為一款懸疑解謎遊戲設計三個關卡機關：包含一個三位數密碼鎖、一個需要特定道具（鑰匙）才能開啟的門，以及一個觸發事件順序判定。請提供對應 JavaScript 程式碼範例。」

3. **介面與視覺設計 (UI/UX)**：
   > 「請使用 Tailwind CSS 設計一個充滿寂靜、復古與懸疑氛圍的清晨 UI 介面，主題色系採冷色調（深藍、灰紫、晨霧白），並包含時間倒數顯示與道具欄 (Inventory)。」

## ✅ 已完成的功能

- [x] **時間循環系統**：完整的倒數計時與重置機制，支援跨循環狀態（記憶/情報）繼承。
- [x] **互動調查系統**：點擊場景物件進行調查，支援文字劇情對話框顯示。
- [x] **背包與道具欄**：可收集、查看並使用特定的解謎道具。
- [x] **關卡機關解謎**：
  - 密碼鎖輸入與驗證機制。
  - 道具與場景物件連動（例如：用鑰匙開門）。
- [x] **音效與氣氛營造**：支援動態背景音樂 (BGM) 與互動音效切換。
- [x] **多結局系統**：根據玩家解開的謎題程度觸發「未完循環」或「突破清晨」結局。

## 🕹️ 操作方式

| 操作按鍵 / 動作 | 功能說明 |
| :--- | :--- |
| **滑鼠左鍵點擊** | 調查場景物件、與 NPC 對話、點擊 UI 按鈕 |
| **鍵盤 W / A / S / D 或 方向鍵** | 控制角色在場景中移動 |
| **I 鍵 / 畫面背包圖示** | 打開 / 關閉道具背包 |
| **Esc 鍵** | 開啟暫停選單 / 關閉當前對話視窗 |
